# R3b: Native macOS open-source dictation apps (competitive landscape, part b)

Date: 2026-10-28. Scope: open-source dictation apps written natively for macOS (Swift/Objective-C), plus one Rust successor (anomalyco/hex) included because its code is Rust and directly portable into our Tauri app. Each finding is tied to the R2 gap analysis (`docs/research/R2-gap-analysis.md`) by row ID (A-xx…E-xx), architecture finding (AF-xx) or decision (DEC-xx).

**Tags.** (obs) = observed: I or a sub-pass read the code, LICENSE, doc or issue cited. (inf) = inferred from what was read. (unk) = unknown. Code paths are relative to each repo root. Line numbers come from shallow clones taken on 2026-10-28 and will drift.

**License status of ideas.** **Code** = permissive license (MIT/Apache/BSD) and file not marked as GPL-derived: may be adapted or ported with attribution. **Idea only** = GPL source, or a GPL-derived file inside a permissive repo: the design may be reused, the code may not, and the code was not read (clean-room) except where noted.

## 1. Method

### 1.1 Searches run (obs)

- `gh repo view` for every named project (BetterWispr, Hex, VoiceInk, FluidVoice, Yap, OpenFlow, AudioWhisper, OpenSuperWhisper).
- `gh search repos --topic dictation --language swift --sort stars --limit 30`: 30 results, used to find Muesli, TypeWhisper, TypeNo, MacParakeet, pindrop, Talkify, Detto, EnviousWispr, SuperDictate, VocaMac and others.
- `gh search repos whisp dictation macos` and `gh search repos Whisp --language swift`, plus GitHub API `whisp in:name` and a web search for "Whisp macOS dictation app open source github". No app named "Whisp" with real users exists (see 1.3).
- Hugging Face API (`/api/models/<id>`) to check cleanup-model license tags.
- For each project: `gh api repos/<r>/license` and the LICENSE file content (decoded, header read), `gh release list`, contributor count, open issues and PRs.

### 1.2 Clean-room process (obs)

- **Permissive (MIT/Apache):** shallow-cloned (`git clone --depth 1`) into `<scratchpad>/clones/r3b-<name>/`. Read only with `rg` and file reads. Nothing was built, installed or run.
- **GPL (VoiceInk, FluidVoice, TypeWhisper, MacParakeet):** only the LICENSE file, README, `docs/`/`spec/` markdown, release notes, websites, Hugging Face model cards and the issue/PR tracker (text) were read. No clone, no source file. Some issue bodies quote snippets; none are carried into this report.
- **Mixed provenance (BetterWispr):** Apache-2.0 repo, but `docs/oss-reuse.md` lists several files adapted from VoiceInk (GPL-3.0, revision c09cc1f), justified as "The repository owner allowed copying VoiceInk code for this feature" (obs). That permission cannot relicense VoiceInk's GPL code (inf). A sub-pass read four of these files (`TranscriptPolisher.swift`, `ContextCapture.swift`, `WebsiteReader.swift`, `CorrectionWatcher.swift`) before finding the doc, then stopped. **Treat these, plus `WritingMode.swift`, `CorrectionReviewer.swift`, `WordAgreementEngine.swift`, `LiveTranscriber.swift` and `APINotesModel.swift`, as idea only, and keep notes on them away from whoever writes our code.**
- License headers were re-checked independently by the lead for all 11 permissive and GPL repos (obs, `gh api repos/<r>/license`).
- Key claims from sub-passes were spot-checked by the lead in the clones: BetterWispr `acceptsFirstMouse`/`NSTrackingArea`; OpenFlow tap watchdog and wake rebuild; Yap `@Generable`/`isFaithful`; Hex legacy `tapIsEnabled` watchdog; hex `paste.rs` Chromium 155/156 detection and `CHORD_BREAKER_KEY_CODE = 0x44`; hex and Muesli process taps; OpenSuperWhisper bundled `ggml-tiny.en.bin`; Muesli `TelemetryDeck.initialize`; Talkify prompt framing and Sparkle `isBusy`; MacParakeet "Idle Pill" spec; FluidVoice PR #193 merge state; TypeWhisper PR #1561 merge state; VoiceInk issue #1000. All confirmed except one correction: **FluidVoice PR #193 (Globe suppression) is closed and not merged** (obs, `merged=false`).

### 2.3 hex, Rust successor (anomalyco/hex) — MIT (bonus, not Swift)

## 6. Summary of the most useful findings per gap cluster

1. **(a) LLM cleanup:** Talkify and Yap (MIT) give a complete Apple FM envelope: fixed injection-safe framing, single-field structured output, greedy decoding, a faithfulness check, a 10 s cancellable race with raw fallback. OpenFlow's regex gate skips the LLM for clean takes. hex's Swift bridge fixes AF-14. For the llama.cpp sidecar, Muesli's Apache-2.0 Qwen3.5 0.8B/2B cleanup GGUFs are the best clean-licensed candidates.
2. **(b) First-run model:** hex has a per-language recommendation table measured on Handy's own transcribe.cpp GGUFs, and starts the download when onboarding opens. Bootstrap options are a bundled tiny.en (OpenSuperWhisper) or zero-download OS speech (Yap/Talkify on macOS 26, BetterWispr on-device SFSpeech). MacParakeet's silent locale rule is the closest to "the user never picks".
3. **(c) Idle pill:** BetterWispr (`acceptsFirstMouse` + NSTrackingArea) and Muesli (hitTest click-through, drag) answer RC-01/RC-03 in code. MacParakeet's spec matches the Flow Bar behavior.
4. **(d) Hotkey:** Hex legacy's tested state machine and tap watchdog plus hex's Rust chord breaker fix AF-08/A-208/A-22. Nobody shipped Globe suppression. FluidVoice's design is unmerged, and listen-only fn opens the emoji picker (MacParakeet #533).
5. **(e) Insertion:** hex `paste.rs` (Rust, MIT) covers the full-flavor clipboard, transient markers, guarded restore and the Chromium 155/156 workaround. TypeWhisper's "ask for the focused window" rule and BetterWispr/Talkify focus-match + copy card give a fail-open no-textbox path. ⌘V hygiene: wait for modifier release, set the device-Cmd bit.
6. **(f) Per-app:** BetterWispr's deterministic tones per app category work without an LLM. Muesli reads browser URLs through AX `kAXDocument` with no Automation prompt. AppleScript URL reading is fragile (VoiceInk #658).
7. **(g) Text features:** MacParakeet's pipeline order (actions → snippets → whitespace) and OpenFlow's non-rescanning replacer address AF-06. Auto-learn exists (VoiceInk, Muesli opt-in) but fails in Electron. Nobody permissive has rich snippets.
8. **(h) History and stats:** Muesli's schema (duration, words, app, daily cache) and VoiceInk's text-free metrics that survive deletion are the model for AF-07. hex defaults to 7-day text-only history; Talkify keeps history off by default.
9. **(i)/(k) Onboarding and updates:** MacParakeet's 4-step flow ends in a real dictation with model prep from Welcome, and hex has an animated drag-tile permission guide. Talkify defers Sparkle updates while dictating (E-215). VoiceInk #829 shows that a signature change wipes TCC grants.
10. **(j) Meetings:** a global Core Audio process tap that excludes our own PID, with a default-output listener, settle-aware rebuild and watchdog (Muesli, hex, BetterWispr; all MIT), solves AF-10's device-switch and own-sound problems with only the audio permission. hex's "meeting chunks only while dictation is idle" is a ready DEC-06 design.
