# R3c: Commercial landscape (public sources only)

Part (c) of R3. It fills R1's `unknown` and `inferred` items about Wispr Flow from Wispr's own public help center, and maps the commercial competitors against the R2 gap clusters (a)-(k).

**Method.** WebSearch and WebFetch on public pages only, fetched 2026-10-28. No sign-in, no installer downloads, no paywalls, nothing decompiled. Quotes are kept under 15 words; everything else is paraphrased.

**Tags.** `documented` = stated on the vendor's own site or docs. `third-party` = a review, roundup or competitor page; treat it as a claim. `vendor claim` = the vendor's marketing, not checked (for example accuracy or speed numbers).

**Dates.** Wispr's help center shows only relative dates ("Last updated N days ago"). The relative date is recorded as seen on 2026-10-28. Help-center pages change often, so recheck before quoting them in a decision.

## 2. Wispr Flow: answers to R1 unknowns

All rows are from Wispr's own help center or site (`documented`) unless the row is marked otherwise. "Mac" means desktop macOS. R1 refs point to `R1-wispr-flow-teardown.md`, R2 refs to `R2-gap-analysis.md` §9 open questions (Q1-Q10) and rows.

### 2.1 Hotkeys, tap vs hold, hands-free (R1 §3 "Timing thresholds unknown", Open item 2; R2 Q1)

| R1 item | Answer | Source | Tag |
|---|---|---|---|
| Tap vs hold threshold | A push-to-talk tap released in under 0.5 s does not paste. Flow waits briefly for a second press, then cancels. Quote: "released in under half a second does not paste". | W2 | documented |
| Double-tap window | Double-press push-to-talk **within half a second** to start hands-free. Command Mode uses the same rule: a double press within 500 ms locks it hands-free. | W1, W2, W4, W21 | documented |
| Third press | A third quick press after a double-press **cancels**. | W1, W2 | documented |
| Does a single fn tap do anything? | No. Under 0.5 s nothing is pasted, then it cancels (above). Assigning fn to Flow also blocks fn's usual system action (quote: "prevents its usual system action"). The docs never mention the Globe-key setting. | W2, W3 | documented |
| Hands-free defaults | Mac: Fn+Space. Macs with no Apple fn key: Ctrl+Opt (push-to-talk) and Ctrl+Opt+Space (hands-free), set during onboarding. Windows: Ctrl+Win and Ctrl+Win+Space (some new setups use Caps Lock). | W1, W3, W13 | documented |
| Stop hands-free | Press the shortcut again (Mac: fn once also works), or click ■ in the Flow Bar. Pressing again **within 0.5 s of starting cancels** instead of pasting. | W1, W2 | documented |
| Cancel | Esc (one binding only; remappable). The cancel notice offers **Undo**, which retries the last transcript and pastes it. Esc does not reach other apps during dictation. Desktop cancels under 0.5 s are discarded. | W1, W3, W2 | documented |
| Presses while busy | Shortcuts are ignored while Flow is stopping, processing, retrying or testing the mic. A new press during processing is ignored (no queue). | W1, W4, W19 | documented |
| Session cap | Warning at 19 min, hard stop at 20 min; the audio is still transcribed. Android: 5 min. | W1, W2 | documented |
| Shortcut grammar | Up to 4 bindings per action (Cancel: 1). Up to 3 keys per combination; a modifier or eligible mouse button is required. Caps Lock alone is allowed only for PTT/hands-free; Esc alone only for Cancel. Left and right versions of one modifier cannot be combined. Stuck keys recover after 10 s. Shortcuts are stored per device and not synced. Some combinations are blocked as system-reserved (Cmd+Space and others). | W3 | documented |
| Overlapping bindings | If hands-free is part of the PTT chord, Flow saves it with a warning ("may lead to conflicts"). Key order matters while recording a shortcut. | W3 | documented |
| Mouse buttons | Middle, Mouse 4/5 and Mac Mouse 6-10 can be bound (hold = PTT, double-tap = hands-free). Magic Mouse and trackpads are not eligible. | W1, W3 | documented |
| Secure Event Input | fn hold-to-talk keeps working; key combinations (Fn+Space, Esc) stop. No on-screen alert. The docs name Terminal/iTerm2 and password managers as usual causes, and a focused password field can turn it on. Workaround: hold fn or double-press fn within 500 ms. | W21, W3 | documented (W21 and W3 differ slightly on detail) |
| Required bindings | PTT, Command Mode, paste-last, copy-last and Cancel must keep at least one binding. Hands-free and Press Enter can be left empty. | W3 | documented |

### 2.3 Insertion, clipboard, no text box, password fields (R1 §1.1 "insertion unknown", R2 Q4)

| R1 item | Answer | Source | Tag |
|---|---|---|---|
| Insertion method | **Clipboard paste, not simulated typing.** On Mac the paste keystroke follows the active keyboard layout (QWERTY V position as fallback); restart Flow after changing layouts. Mac needs Accessibility for insertion. | W2, W19, W20 | documented |
| Clipboard restore | Previous clipboard is restored after the text lands, unless you copied something new meanwhile. Mac waits up to ~7 s in slow apps such as Chrome; until then, pasting again pastes the dictation. Mac does not restore files, PDFs, RTFD or sound. Flow asks clipboard managers to skip dictated text and respects password-manager exclusions. | W1, W2, W19 | documented |
| No text box | Insertion needs a focused editable field. Without one, the **recovery card** appears: transcript, "Select a textbox first, then dictate", and Copy. Copy replaces the clipboard, which is not restored afterwards. An empty or formatting-only transcript shows "Click a textbox and use {shortcut} to paste" and copies nothing. | W19, W20 | documented |
| Failed insertion | Transcript stays on the clipboard. Paste-last (⌃⌘V) and copy-last (⌃⌘C) recover it. Paste-last also cancels any dictation still processing. | W1, W2, W20 | documented |
| Password fields (desktop) | Context Awareness never reads password-field contents, but custom or web password fields "may be read like normal text fields". The docs do not say whether dictation is inserted into secure fields on Mac. Android hides the bubble in password, numeric and phone fields and in banking apps. | W10, W22, W19 | documented (Mac insertion: unknown) |
| Undo after dictation | ⌘Z right after a dictation reverts the pasted text (cleanup included, since one paste is made). "Undo AI edit" in history restores the raw text **for you to copy and paste**; it does not re-paste. Answers R2 Q8 and DEC-19. | W9, W11 | documented |
| Offline | Being offline does not block desktop dictation. If transcription fails, Flow saves the audio for retry. Transcription itself is cloud-only, so no text arrives until online. | W1, W25 | documented |
| Electron | Preference files are named `com.electron.wispr-flow*`, with a separate `accessibility-mac-app` helper. This suggests an Electron app with an AX helper process. | W30 (file names), W29 | inferred from documented paths |

### 2.5 Snippets, dictionary, voice commands (R2 Q7, DEC-20)

| R1 item | Answer | Source | Tag |
|---|---|---|---|
| Snippet matching | Triggers work **alone or inside a sentence**. Spoken alone, the trigger's punctuation, symbols and spacing are ignored. Inline, internal punctuation must match. A trigger must not touch letters, digits or underscores. Possessives expand; "n't" contractions do not. | W6 | documented |
| Snippet case | Case never matters when spoken; the expansion keeps its saved casing. | W6 | documented |
| Snippet conflicts | Personal beats team. Otherwise the **longest match by characters** wins. Dynamic variables (date) are not supported on desktop. | W6 | documented |
| Snippet limits | Trigger ≤60 chars; desktop expansion ≤4,000 chars including formatting. Rich text: bold, italic, lists, links. Falls back to plain text in apps that reject formatted paste or when the same trigger appears twice. Multi-line expansions keep blank lines. Import ≤3 MB / 1,000 items (format not stated). | W6 | documented |
| Dictionary matching | Corrections match whole words regardless of case and keep the saved capitalization. They are literal and not language-aware; the longer phrase wins. Possessives are corrected, "n't" contractions are not. Max 60 chars per field. | W7 | documented |
| Auto-learning | **Mac/Windows only, behind an "auto-learn words" setting.** It watches for your edits to dictated text. Not every correction becomes an entry, and learned words are announced in a batch notification. Skips paths, URLs, emails, code symbols, IDs, numbers, dates, emoji, everyday words, very common names, famous names and everyday acronyms. Deleted words are never re-added. The Data Controls page says auto-add "monitors the text box to detect spelling edits." | W7, W25 | documented |
| Voice commands | "new line / next line / line break / skip a line", "new paragraph", punctuation names. They work regardless of the Smart Formatting setting. Lists form from "one… two…" or "first… second…". | W11 | documented |
| Backtrack | "actually", "scratch that", "never mind" or a restatement removes the clear self-correction ("coffee at 2 actually 3" gives "coffee at 3"). Ordinary "actually" is kept. | W11 | documented |
| Trailing periods | Removal depends on the Style (Formal never; Casual up to 10 sentences; Very casual unlimited; Excited/none up to 2 sentences in messaging apps). | W11 | documented |
| Press Enter by voice | Experimental, off by default, paid only. Saying "press enter" at the end presses Enter **only after a successful paste**. A one-time prompt confirms it. | W1 | documented |

## 5. Ideas worth adopting (tied to R2 ids)

Each idea comes from a documented source. They are ordered by value to our product, not by effort.

1. **Wispr's exact tap grammar** for fn: a hold under 0.5 s never pastes, a double-press within 0.5 s locks hands-free, a third press cancels, a stop within 0.5 s of start cancels [W1, W2]. Settles A-23, A-34, DEC-09 and R2 Q1 without another observation session. Replace Handy's single-tap lock with this.
2. **No-fn fallback chosen in onboarding:** Ctrl+Opt (PTT) and Ctrl+Opt+Space (hands-free) when no Apple fn key is present [W3, W13] → A-202, A-35, B-23.
3. **Secure Input behavior:** a modifier-only fn hold survives Secure Event Input while key combinations do not [W21]. That argues for fn as the default (DEC-09). Also show a pill hint (A-205), which Wispr lacks ("no on-screen alert").
4. **Clipboard policy:** restore with a delay of up to ~7 s for slow apps, keep anything the user copied meanwhile, mark the dictation transient for clipboard managers, and say which formats cannot be restored [W2, W19] → A-47, A-48, AF-17.
5. **Recovery card rules:** show it only when there is no editable field, keep the clipboard untouched unless the user presses Copy, and add paste-last/copy-last shortcuts [W19, W20] → A-15, A-26, A-27, A-51, A-53.
6. **Click-to-start keeps the target focused** [W2] → A-04, A-52 (confirms the non-activating panel is the right design; RC-01).
7. **Bar follows the cursor's display, avoids Dock and menu bar, flush in full screen, "Hide for 1 hour" on right-click, hidden until onboarding ends** [W16, W17] → A-01, A-17, A-66, A-212, DEC-25.
8. **Cleanup defaults:** Light by default, None/Light/Medium only, skip cleanup in AI apps and terminals, paste raw on any failure, keep the original [W9, W11] → D-01-D-09, D-208, DEC-03, DEC-13.
9. **Backtrack and the trailing-period rule per style** [W11] → D-16, D-23/D-24. Mostly prompt and rules work, so it is cheap once the LLM exists (D-67).
10. **Snippet matching spec** (alone or inline, word-boundary rule, case-insensitive trigger, saved casing, longest match wins, contractions excluded) [W6] → D-53, C-72. Implement it deterministically after the LLM and after normalization (AF-06).
11. **Dictionary correction rules** (whole word, case-insensitive, literal, longest wins) [W7], plus Spokenly's **"before or after AI" choice** [SP2] → D-48, C-63.
12. **Auto-learn as an opt-in setting with skip lists and a batch notification**, never re-adding deleted words [W7] → D-52, DEC-20. Local AX read-back is a privacy win when it never leaves the Mac.
13. **Transforms with no selection:** use the field contents, else the last dictation from the past 60 s [W5] → D-202. **Aqua's single-key Edit Mode** (selection plus key = edit, no selection = dictate) [Q3] is a simpler alternative to a separate Command Mode chord → D-44, D-45, A-29.
14. **Auto Apply failure = paste original; skip runs within 5 s** [W5] → D-42, D-11.
15. **Context Awareness exclusions list** (banking apps, URL bars, password and numeric fields, placeholders, the app itself) and clearing context after each dictation [W10] → D-58, DEC-24. Add Superwhisper's idea of **showing the exact context used in History** [S11] → C-41.
16. **Web-app detection by browser domain** is what Wispr does [W8, W10] → D-22, DEC-23 (AX URL reading is the matching local approach).
17. **Superwhisper's "reprocess with another mode" and retention selector (Forever default)** [S13] → C-43, C-46, DEC-07.
18. **WPM on silence-trimmed speech time; CJK/Thai counted without spaces; heatmap bands** [W27] → C-31, C-55, C-212, DEC-11.
19. **Updates that wait for idle (≥20 min after last dictation), never mid-dictation, relaunch quietly to the bar, retry with backoff** [W29] → E-51-E-53, DEC-16.
20. **Mic borrowing during a meeting** (dictation takes the mic, Notetaker keeps system audio, a "Dictated" marker) [W37] → E-47, DEC-06. This is cheaper than a second supervisor.
21. **Apple's 30-s-silence auto-stop and "type while dictating"** [AP1] → A-13 safety net for hands-free; and Spokenly's **paste + Enter per mode** and Aqua's **"send it" with chosen send key** [SP2, Q3] → A-28, A-54, D-61.
22. **Mic-ranking with automatic fallback (clamshell)** [W39 Jun 24] → A-38, A-43, A-211.

## 6. Differentiators for a free local product

What paid apps do not do, or do only behind a paywall or a cloud dependency:

1. **Local AI cleanup in every language, free.** Wispr, Aqua, Willow, Monologue and Typeless run cleanup in the cloud. Superwhisper's only local LLM is English, Message/Mail only, and Pro [S7]. Monologue offline gives raw text [MO1]. A bundled local LLM (D-67, AF-01) with None/Light/Medium is unique at $0.
2. **No account, no sign-in, nothing lost on sign-out.** Wispr needs a browser sign-in before anything works, and signing out deletes local history [W13, W30]. Spokenly Local is the only rival with no account, and it still sends analytics unless Local Only Mode is on [SP2].
3. **Zero network by default, verifiable.** Wispr uploads app name, URL and metadata even with training off [W23, W10]. Ship the equivalent of Spokenly's Local Only Mode as the **default**, with an offline indicator and a published network inventory (AF-12, DEC-16).
4. **Silent model choice.** Every local competitor shows a model library (Superwhisper, MacWhisper, Spokenly, VoiceInk), and Superwhisper's first mode silently uses cloud models [S3, S6]. Picking a model silently on-device (B-47, B-49, DEC-02) matches Wispr's no-decisions feel without the cloud.
5. **Best local models without a paywall.** Superwhisper puts Parakeet and Cohere Transcribe behind Pro [S6]; Spokenly puts the notch/capsule overlay behind $29 [SP1]. Ship the strongest local ASR plus a polished pill free.
6. **Unlimited dictation, no word caps, no session cap.** Wispr free is 2,000 words/week, Aqua 1,000 words, Monologue 1,000 words, and Wispr caps sessions at 20 min [W26, Q2, MO1, W1]. Offer no caps, with an Apple-style silence auto-stop instead (§5.21).
7. **Command Mode, voice "Press Enter" and auto-learn free and on by choice.** These are paid-only and off by default at Wispr [W4, W1]; dictionary and custom instructions are Pro at Aqua [Q2].
8. **Local context awareness with a visible receipt.** Competitors send context to the cloud (Wispr, Aqua screenshots) [W10, Q3]. Reading AX text locally and showing "what context was used" in History (Superwhisper only shows the prompt [S11]) makes privacy legible.
