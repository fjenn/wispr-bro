# R5 review: build plan for Wispr Bro

Reviewer pass over `R5-prd-and-slices.md` against R1, R2, R3, R4 and the R4 GPL addendum, and against the Handy code in this repo (Tauri 2.11.5, tauri-specta 2.0.0-rc.21, handy-keys 0.3.4). Code was opened where a plan claim depends on it; paths are cited in the Evidence column.

## Summary

**Verdict: good plan, but not ready to build as written. Fix the 5 blockers before F-05 and S-01 start.** The plan is thorough and covers every R2 row. A script check found all 492 R2 ids placed. Every slice's "R2 rows closed" list matches the appendix, and no HAVE, OUT or XREF row is mis-filed in §13.1. Licence and provenance handling is mostly correct: mado comes from the crates.io tarball, the BetterWispr GPL files keep VoiceInk attribution, the 12 Moonshine models are hidden, and AGPL files are marked.

The real problems are in four places:
- **Plumbing claims that the Handy and Tauri code does not support:** plugin command ACL, plugin setup order, the raw key stream, and the overlay level gate.
- **A CI guard that fails on day one.**
- **Forward dependencies** hidden inside exit criteria.
- **A few owner-level choices** that were filed as defaults.

## Eight-line summary

1. Verdict: the plan is strong and has full R2 coverage, but it is not buildable as written. Fix the blockers before F-05 and S-01.
2. Blockers: 5 (plus 27 major and 16 minor).
3. Fix 1: fork commands fail Tauri's plugin ACL and the `collect_commands!` fallback cannot compile. Use a composed invoke handler (or InlinedPlugin in `build.rs`) (RV-01).
4. Fix 2: fork plugin setup runs before Handy's managers exist. Move manager-dependent init to `RunEvent::Ready` (RV-02).
5. Fix 3: handy-keys gives no raw key stream, and `owns()` drops fn blocking. S-01 must run its own `KeyboardListener::new_with_blocking` (RV-03).
6. Fix 4: Handy's overlay-off setting gates mic-level events, so the pill waveform is dead. Move the mirror hook before the gate and skip building Handy's overlay (RV-04).
7. Fix 5: the CI host and telemetry guards fail on day one because of upstream URLs and `unicode-segmentation`. Baseline upstream, scan fork paths and the bundle, add a runtime egress test (RV-05).
8. Next: resolve the forward dependencies and split the oversized slices (RV-15, RV-16), stop clipboard writes on queued delivery (RV-06), and send DEC-26, the fn fallback/private APIs, Intel and the Wispr-wording question to the owner.
