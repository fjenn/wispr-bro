## Summary of Handy's Hub today (verified)

The main window is a settings app: a 160 px sidebar (`src/components/Sidebar.tsx:96`) with General, History, Models, Advanced, Post Process (only when enabled), Debug (only in debug mode) and About (`src/components/Sidebar.tsx:34-77`). The default page is General (`src/App.tsx:87-88`), not History. A footer shows the model selector, background-job status, update checker and version (`src/components/footer/Footer.tsx:30-45`). The window is 720 x 600 with the standard macOS title bar (`src-tauri/src/utils.rs:26`, `src-tauri/src/lib.rs:968-974`). History is a flat, infinitely scrolling list with copy, star (keep), re-transcribe, delete and an inline audio player per row (`src/components/settings/history/HistorySettings.tsx:426-549`). The history DB stores raw and LLM text separately, but not duration, app, word counts or edits (`src-tauri/src/managers/history.rs:22-45`). **History keeps only the last 5 dictations by default** (`src-tauri/src/settings.rs:676-682`), and retention deletes the whole row, text included (`src-tauri/src/managers/history.rs:455-483`).

## Data model gaps

History table today: `id, file_name, timestamp, saved, title, transcription_text, post_processed_text, post_process_prompt, post_process_requested, source_name, language, language_source` (`src-tauri/src/managers/history.rs:22-45`). verified.

Missing per dictation (needed by home stats, Insights, Undo, per-app style):
1. `duration_ms` (speech length) for WPM. Sample count exists at save time (`src-tauri/src/actions.rs:700`) but is dropped.
2. `word_count` of final text (or compute at insert), with a CJK-aware rule.
3. `app_bundle_id`, `app_name` (and later `app_category`) of the target app. No capture code exists.
4. `asr_text` before custom-word and filler fixes. Today `transcription_text` is already post-fixed (fixes happen inside `post_process_transcription_text`, `src-tauri/src/managers/transcription.rs:1643-1660`), so "exact transcript incl. mistakes" (Wispr Auto cleanup None) is not recoverable.
5. `fixes_dictionary`, `fixes_fillers`, `fixes_ai` counts, plus a per-word correction log for "Most corrected word".
6. `display_variant` / `ai_edit_undone` for Undo AI edit.
7. `previous_text` (one level) so Retry is reversible.
8. `audio_deleted_at` (or nullable `file_name`) so audio can expire while text stays.
9. `pasted_ok` / outcome (pasted, copied-only, failed). The outcome exists as an event (`src-tauri/src/actions.rs:829-843`) but is not stored.
10. `flagged` (if Flag becomes "wrong transcript").

Missing aggregates (must survive retention and deletion of rows): a `daily_stats` table (date, words, dictations, speech_ms, fixes, by app category) for total words, streak, calendar, WPM trend, Voice Profile unlock.

Missing stores:
- Dictionary entries with metadata (kind word/replacement, from, to, source user/suggested/import, created_at, hit_count). Today a flat `Vec<String>` in settings (`src-tauri/src/settings.rs:463`).
- Snippets (id, trigger, body_plain, body_html, created_at, use_count).
- Scratchpad notes (id, title, body, pinned, created_at, updated_at, last_opened).
- Local notifications inbox (id, kind, title, body, created_at, read).
- UI state in settings: dismissed banners, seen "New!" tags, setup checklist progress, sidebar collapsed, display name, `show_in_dock`, notification toggles (suggestions, announcements, milestones), scratchpad open behavior, scratchpad shortcut binding.
- Settings that need new defaults: `history_limit` 5 and retention `PreserveLimit` (`src-tauri/src/settings.rs:676-682`), `audio_feedback` false (`settings.rs:999`), `autostart_enabled` false (`settings.rs:592-594`).

## Rough edges found in code

1. **History shows and copies pre-LLM text.** Display uses `entry.transcription_text` (`src/components/settings/history/HistorySettings.tsx:529`) and copy too (`HistorySettings.tsx:292`), while the pasted text and tray "copy last" use `post_processed_text` (`src-tauri/src/tray.rs:611-616`). verified
2. **Default history keeps 5 dictations** and deletes their text, not only audio (`src-tauri/src/settings.rs:676-682`, `src-tauri/src/managers/history.rs:455-513`). Any stats or search built on rows would silently lose data. verified
3. `history_limit` accepts 0 (`src/components/settings/HistoryLimit.tsx:23`); with "keep N" retention, cleanup then deletes every unsaved dictation right after it is saved (`history.rs:309, 503-505`). verified (logic), inferred (user impact)
4. Frontend fallbacks disagree with backend defaults: retention UI falls back to `"never"` (`src/components/settings/RecordingRetentionPeriod.tsx:19`) while backend default is `PreserveLimit` (`settings.rs:680-682`). verified
5. Retry overwrites the previous text with no way back (`history.rs:384-410`). verified
6. Delete has no confirmation or undo (`HistorySettings.tsx:405-412`). verified
7. Custom-word input strips apostrophes and quotes (`src/components/settings/CustomWords.tsx:14-18`), so "O'Brien" or "Don't" become different words. verified
8. Retention cleanup runs only on save and on setting change (`history.rs:309`; `src-tauri/src/commands/history.rs:107-109, 136-138`); an idle app never prunes (inferred; no timer found in files read).
9. Version fallback hard-coded to "0.1.2" in two places (`src/components/footer/Footer.tsx:22`, `src/components/settings/about/AboutSettings.tsx:25`). verified
10. `@tauri-apps/plugin-sql` is still a frontend dependency (`package.json:40`) although history moved to rusqlite and `src/` has no import of it. verified
11. Model selector in the footer and model submenu in the tray (`Footer.tsx:33`, `tray.rs:545-560`) contradict "the user never picks a model". verified
12. Several user-facing strings live under `settings.debug.*` keys although shown in normal pages (e.g. mute while recording, history limit, retention: `MuteWhileRecording.tsx:23`, `HistoryLimit.tsx:30`, `RecordingRetentionPeriod.tsx:47`). Cosmetic, but a cleanup point when regrouping. verified
13. Post-processing defaults to the "openai" provider id (`settings.rs:710-712`) and can send transcripts to a cloud API. Off by default (`settings.rs:696-698`) and behind Experimental, but must be removed or replaced with a local-only provider for this product. verified
14. Main window min size equals default size, 720x600 (`src-tauri/src/lib.rs:969-970`), too small for a Hub with a stats rail. verified
