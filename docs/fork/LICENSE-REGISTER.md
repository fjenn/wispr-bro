# Licence register

The source of truth for every licence that reaches a Wispr Bro user: the
app's own code, the third-party code it links, and the separately licensed
model weights and fonts. It is R4 §5 (`docs/research/R4-parts-bin.md`)
adapted to the owner decisions DEC-26 (CC-BY-4.0 speech weights may be
silent defaults, with attribution) and DEC-27 (models that are never a
default, and the ones hidden from our catalog view). F-04 created it; every
slice that adds a model, font, asset or a new licence updates it in the same
PR.

"Default?" means the item may ship, or be fetched silently, without the
user choosing it. Code enforcing it: `src-tauri/src/fork/models/license_filter.rs`
(`may_be_default`, `catalog_view`).

## 3. How it is kept current

- `scripts/wb-notices.ts` fails when a CC-BY catalog model has no NOTICE §6
  entry, a shipped package has an unaccepted licence or an unlisted NOTICE
  file, or a crate compiles native code that is not in its manual C/C++ list.
- A new model family in Handy's catalog (upstream sync) gets a row here
  before S-07b may pick it.
- The About / Acknowledgements page (S-39) renders NOTICE §6 and
  `THIRD-PARTY-NOTICES.md`.
