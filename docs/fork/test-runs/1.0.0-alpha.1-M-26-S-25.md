Found and fixed during the run: the save panel is a separate process and
ignores the Unicode-string key events the S-16 driver typed, and an event
from a `.hidSystemState` source kept the ⌘ of the previous command, so "m"
in the typed path minimized the window; `ui.swift` now has a `keys` command
(US-layout key presses with explicit flags).

Changed after the release run: the exported PNG got a 24 px margin (the cards
touched its edges). It only adds html-to-image `style`/`width`/`height`
options, no new resource type under the CSP; Playwright checks the size
(2 × (area + 48 px)) in Chromium. The release build was not rebuilt for it.

Not run: the Web Inspector console of the release build (a CSP violation
there would not reach the log; the PNG rendering with the inlined fonts is
the evidence that nothing was blocked), VoiceOver by ear, a person's own
history, a live unlock by a real take (the unlock was seeded across a
relaunch; the live refresh is S-15a's `ForkStatsUpdated` path and is covered
in Playwright), Arabic and other locales in the real app (Playwright only),
the Developer ID build (F-02).
