# S-07a real-Mac run: first speech model, mic gate, "Setting up"

- **Build:** `1.0.0-alpha.1` debug, `--no-bundle`, test identity
  `com.wisprbro.s07acheck` (a product build through
  `fork::is_test_identity`), portable mode (`portable` file next to the
  binary, data in `Data/`), every run from an empty `Data/`.
- **Machine:** M-26 (M5 Max, macOS 26.6.2). Other agents shared the Mac;
  GUI and speaker steps held `~/wb-bench/gui.lock`.
- **Network:** the model files came from `scripts/wb-s07a/hf-mirror.py`
  (a loopback stand-in for Hugging Face serving `~/wb-bench/asr`, one
  throttled link) through `HF_ENDPOINT`; one run used the real
  `huggingface.co`. The macOS preferred languages on this Mac are en + nl;
  the English runs set Handy's `spoken_languages` to `["en"]`.
- **Audio:** two `say` sentences played once each through the speakers
  (the mic gate needs the real record path); everything else ran without
  audio. Takes were started and stopped with SIGUSR2 (Handy's toggle, a
  hands-free take), no key events.
- **Scripts:** `scripts/wb-s07a/{hf-mirror.py,take.sh,run.sh,copy.sh,scenarios.sh}`.

## Findings and follow-ups

1. **A card in a freshly built web view did not paint once** (first run:
   "Setting up" had been dismissed by an Esc from elsewhere, the web view
   was destroyed, the card arrived 6 min later on a new web view that never
   reported its paint; the bar stayed on its native bridge capsule). Not
   reproduced in the second run (the web view was still alive). Fix: the
   controller now resends an unpainted state after 2 s and rebuilds a web
   view that has not painted after 8 s (`fork::pill`, `RESEND_UNPAINTED_MS`,
   `REBUILD_UNPAINTED_MS`). Not yet seen in action on the real Mac.
2. **Resume after a quit** does not happen (above). A clean cancel at
   `ExitRequested` (so hf-hub commits its offset) is the likely fix; it
   belongs with S-07c's quit handling.
3. **English at 10 Mbit/s** misses §5.3 with the Q8_0 starter (134 s). A
   smaller quant (Q5_K_M 101 MB ≈ 81 s) or whisper-base (85 MB) on slow
   links would meet it; quality of those quants on our script is unmeasured
   (RS-09 measured Q8_0 only).
4. Esc anywhere dismisses "Setting up" (by design: Esc closes the bar's
   messages); the take still arrives on the card.
