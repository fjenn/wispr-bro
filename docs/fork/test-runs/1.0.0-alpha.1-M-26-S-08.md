Drivers: `scripts/wb-s08/run.sh` (cases), `grant.sh` (first Microphone
prompt → Allow by AX), `setup.py` (profile), `hal.swift` (CoreAudio state
with exact volume bits, a public aggregate as a stand-in USB mic, AX
buttons). Takes were toggled with SIGUSR2. Every case held
`~/wb-bench/gui.lock`. Default input and output were read before and after
the run and are identical (built-in mic; speakers unmuted, volume scalar
bits `3effffff`). The bundle, its TCC entries (`tccutil reset All`), its
LaunchServices registration and its WebKit/Caches folders were removed.

Note on the run: `syspolicyd` was crash-looping on this Mac (segfault, 19+
successive crashes, respawned every ~20 min), so every first exec of a
non-Apple binary (bun, cargo, the test bundle) waited up to 20 minutes.
It did not change any result, only the timing of the run.
