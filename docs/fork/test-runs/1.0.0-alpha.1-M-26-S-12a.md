## S-12a.3: no network

The sidecar listened only on `127.0.0.1` (lsof: one `TCP 127.0.0.1:50815
(LISTEN)`, no other socket) and runs with `--offline`; the cleanup path has
no other client (`fork/net.rs` refuses non-loopback URLs). The Wi-Fi was not
switched off: the Mac is shared.
