Found and fixed during the run:

- Handy's `AudioPlayer` starts a lazily loaded source only from its own
  button, so the first Play only opened an idle player. History's Play now
  resolves the file first and opens the player with the source, playing.
- Radix's menu trigger opens on pointer-down or a key, not on an AX press
  (a synthetic click): the driver focuses ⋮ and presses Return. A mouse
  click works for people.
- `ax.swift` matched "Dictation" in the Flow Bar's "Dictation bar" button
  before the sidebar item and started a hands-free take; it was cancelled at
  once with the bar's own Cancel (nothing saved, nothing pasted). The driver
  now has `=Label` for an exact match, `move` (another test app's window sat
  at the same default position) and `raise`.

Not run / not verified: Save audio as… in the real app (above); Medium
cleanup on a retry actually applied (the sidecar's 2.6 s deadline ran out
twice at a machine load average above 100 with several builds running, so
the retry kept the deterministic text, which is the fail-open path); the
10,000-row scroll in WebKit (Playwright measured it in Chromium: 100 pages on
demand, < 80 rows in the DOM, scroll-step p95 86 ms at load average ~150);
VoiceOver by ear; a person's own history and voice; other locales in the real
app (Playwright covers Arabic RTL); the Developer ID build (F-02).
