The test build overrides `bundle.externalBin` with an empty list (no LLM
sidecar is needed: the run was made before S-12a landed, with Handy's
post-processing off).
`scripts/wb-s17/setup.py` set a returning user (English, ⌘V, no VAD) and
emptied `snippets`. The snippet was added through the page with
`scripts/wb-s16/ui.swift` (events only into the test app's own window, only
while it is frontmost, under `~/wb-bench/gui.lock`): trigger `my address`,
text `Alex Morgan⏎12 Harbour Lane⏎Kiel 24103` (made up), typed with Return
in the text field, saved with the dialog's button. Takes ran through the
real record path (SIGUSR2 → microphone → Parakeet → pipeline → stage 11 in
`deliver` → paste or typing) with `scripts/wb-s17/run.sh`, which reuses
S-11's `take.sh` and pages; the speech was `say -v Samantha` through the
speakers ("My address." / "Please send the parcel to my address by
Friday."). The general pasteboard was snapshotted before each run and put
back after it (`scripts/wb-s17/clip.swift`): same items, types and sha256
before and after.
