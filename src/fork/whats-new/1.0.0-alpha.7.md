## Wispr Bro 1.0.0-alpha.7

- Wispr Bro now runs on Intel Macs too, with every feature.
- If macOS keeps an old Accessibility or microphone entry from an earlier copy, setup now offers "Reset and ask again", so you can finish.
- Dictating into Wispr Bro's own windows, like a Scratchpad note, adds the space before your words like everywhere else.
