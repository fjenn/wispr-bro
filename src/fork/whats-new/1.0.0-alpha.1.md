## Welcome to the first Wispr Bro alpha

- **Dictate anywhere.** Hold fn, speak and let go: clean text lands in the field you are typing in.
- **Everything stays on your Mac.** Speech recognition and cleanup run locally. There is no account and nothing is sent anywhere, except update checks with GitHub and model downloads from Hugging Face.
- **Updates that never interrupt.** New versions download in the background and install only while you are not dictating, or when you quit.
